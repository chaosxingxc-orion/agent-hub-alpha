```sh
python3 -I tools/check_snapshot.py <report.pdf>
```

## 口径约定

- **主体与单位**：本集团（合并口径）；金额为人民币百万元，比率为 %。
- **期间**：2025 年对比 2024 年。上年数取本报告的对比列，不另找 2024 年报（第二章未提及重述）。
- **变化**：金额类写增减百分比（`pct`）；比率类写百分点（`pp`，2025 减 2024，正为上升）。比率类写成百分比算错，见反例 C04。
- **页码**：同时记 `pdf_page`（从 1 起算）和 `printed_page`。正文部分印刷页码 = PDF 页序 − 1；审计报告与财务报表部分另有页码，`printed_page` 填 `null` 或该部分页码。
- **引用**：`quote` 是该页的原文行，核验时在所引页逐字查找。
