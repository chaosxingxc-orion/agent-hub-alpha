# MR: claim-gate v2.7.2 — 反序读数档 REDCOUNT ＋ 叙事帧 skip ＋ D1 真值套件随附

## 做完了什么

1. **REDCOUNT 检测档**：变异电池状态读数"色 token 在数字前"的反序形（红/绿状态对）
   此前为三版共同盲区。按 PROGRESS 分数形先例另立 regex、挂 find_claim 兜底链尾——
   继承 ±8-row 证据窗语义，单位表与 census 钉零触碰，守卫四层逐成员双向钉。
2. **叙事帧 skip**：裸"两+个"回指读法（失实点在别处、计数本身非声明）以第三枚代码级
   skip 闭合，含前导空格逃逸修正；阿拉伯孪生形与复合/前缀形显式不伤。
3. **D1 真值套件随附**（本 MR 的主体价值）：十事件语料（真实失实事件的段级复原＋
   双控制段）× 四代闸 = 48 格判定矩阵、声明级明细、两台行为变异电池、幂等装配器。
   评测从"设计期信用"变为可复跑工件。

## 有什么作用

- **回归地基**：今后任何闸改动重跑跑分器即得 48 格对差＋声明级明细；行为变异电池把
  "删守卫仍全绿"的静默回归直接判红（守恒不变量：每修复配活探针）
- **治理输出**：评测设计三律（注记剥离/声明级判定/判别式控制段）与真源单源家法在
  README/architecture/rules 成文，可迁移到同类词法检查器
- **判别式控制段**：合法段携带特定反引号证据命令，对未修血统必然误报、对已修血统必然
  放行——血统病灶的存活检测器，不依赖版本号自述

## 兼容性与边界

- 不动：单位表、census、CMD 表、窗口语义、既有模式接口（电池 V10 腿含盘-账一致性复核）
- 1.00 仅覆盖十事件套件面：真载体洪峰（单位集病，另案）、隔词闭合形（现文法外，
  truth 表已如实挂注）、零载体残差（闸内注释⑤注册挂账，载体先于扩展）
- 本 MR 不含任何战役内部文档；results 为打码拷贝，桥哈希见 provenance.json
