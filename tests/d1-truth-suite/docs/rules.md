工具表真源 `_CMD_TOOLS`（行首形态与反引号形态派生自同一元组，镜像分裂结构上不可表达）：

```
grep -n "_CMD_TOOLS" gates/claim-gate-v2.7.2.py | head -3
```

## 三枚代码级 skip（词法命中后仍豁免，skip-then-continue、绝不吞行）

1. `类`+`比` 相邻（chmod 类比形"0600 类比"）
2. `零样本` 连写（ML 术语，非零计数）
3. 裸 `两+个` 帧（回指/叙事读法——裁决依据与代价见闸内注释；阿拉伯数字孪生形
   「2 个」**不受影响**，`一+个` 维持 v2.0 既有裁决不切，复合形「两百个」「共两个」不切）

每枚 skip 带双向钉（selftest 常跑）：
```
python3 -I gates/claim-gate-v2.7.2.py --selftest
```
