# 指标口径字典（W01 冻结 · v1）

> 指标专员与核验器的唯一口径依据。值照抄原文，本字典只定义"什么是对的"。

## 八指标定义与单位白名单

| Key | 名称 | 单位 | 口径要点 | 原文常见位置 |
|---|---|---|---|---|
| OPERATING_REVENUE | 营业收入 | 亿元 | 集团合并口径（非母公司单体） | 经营概况/利润表附注 |
| NET_PROFIT_ATTRIBUTABLE | 归母净利润 | 亿元 | "归属于本行股东的净利润"，扣少数股东权益 | 经营概况 |
| NET_INTEREST_MARGIN | 净息差 | % | 利息净收入/平均生息资产（日均，非期末） | 经营概况/净利息收入节 |
| COST_INCOME_RATIO | 成本收入比 | % | 业务及管理费/营业收入 | 经营概况 |
| NPL_BALANCE | 不良贷款余额 | 亿元 | 五级分类次级+可疑+损失 | 风险与资产质量 |
| NPL_RATIO | 不良贷款率 | % | 不良余额/贷款和垫款本金总额（期末） | 风险与资产质量 |
| PROVISION_COVERAGE | 拨备覆盖率 | % | 贷款减值准备余额/不良贷款余额 | 风险与资产质量 |
| CET1_RATIO | 核心一级资本充足率 | % | 监管口径（非总资本充足率、非一级资本充足率） | 资本管理 |

## 机器可复算口径（checker 规则库）

核验器对以下口径做确定性复算，偏差超容差即 BLOCKING（CALC_MISMATCH）：

1. **不良率** = 不良贷款余额 ÷ 贷款和垫款本金总额 × 100，容差 ±0.05pp；
2. **拨备覆盖率** = 贷款减值准备 ÷ 不良贷款余额 × 100，容差 ±1pp（当快照含减值准备数据时启用）；
3. **成本收入比** = 业务及管理费 ÷ 营业收入 × 100，容差 ±0.5pp（当快照含管理费数据时启用）。

复算基数从引用页原文正则定位（约定口径词：「贷款和垫款本金总额/贷款总额」「贷款减值准备」「业务及管理费」）。**基数缺失时降级 WARNING（DERIVED_BASE_MISSING），不得误杀**。

## 期间规则

- 本期=报告年度；同比论断须同时含本期与上期数值；
- 上期数据必须来自上年度报告的独立信源（跨期信源注册），禁止用本期报告里的"上年同期"栏做唯一依据（防排版错位）；
- 累计口径（年初至报告期末）vs 时点口径（期末余额）不得混用。

## 派生值标注协议

任何非照抄的计算值（同比增速、占比变化）必须：`基于 [C-k] 计算：<算式>`，且算式内的输入值必须与引用的指标 artifact 一致。核验器核验算式存在性与输入一致性（算式中的数字必须在引用证据中出现）。
