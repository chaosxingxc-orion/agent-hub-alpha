# 引用格式与论断标注规范（[C-n] 协议）

> 主笔与分析师的输出契约。核验器按本规范逐条核验。

## 论断标注

1. 每条事实论断正文后紧跟引用标记 `[C-n]`，n 全局递增、全篇唯一；
2. 一个论断恰好一条主引用；辅助证据用补充引用 `[C-n]（辅）`，不支持一引多断或一断无引；
3. 推断性语句（"可能/或将"）不得引用事实标记——推断要么删掉，要么转为带数据支撑的论断。

## 引用记录（citations 数组条目）

```json
{
  "claim_id": "C-3",
  "claim_text": "2025年净息差1.98%",
  "source_document_digest": "<快照页 sha256>",
  "page": 12,
  "evidence_excerpt": "净息差1.98%",
  "evidence_excerpt_digest": "<摘录 sha256>"
}
```

- `evidence_excerpt` 必须是快照页原文的**连续子串**（逐字符，含标点）——checker 用 contains 比对；
- 数字论断的摘录必须包含该数字原文形态（千分位逗号须保留）；
- 摘录长度建议 8–60 字：太短不足以支撑语义判定，太长稀释焦点。

## 派生值标注

```
基于 [C-1] 计算：(1,405.66 - 1,326.45) / 1,326.45 × 100 ≈ 5.97%
```

- 算式中的每个输入数字必须出现在被引证据中（checker 核验）；
- 结果四舍五入到两位小数并写明"约"；
- 禁止无算式的百分比（"大幅增长"不接受——写不出算式的判断不写）。

## 支持度期望

- **SUPPORTED**：摘录含论断全部关键要素（数字+期间+口径词）；
- **PARTIAL**：数字命中但期间/口径缺失 → 会收到 WARNING，建议补充摘录或改写论断；
- **UNSUPPORTED**：数字或实体全不匹配 → BLOCKING，必须修订。

## 章节结构

- `sections[].claim_ids` 必须与正文 [C-n] 标记一一对应（遗漏即 UNCITED_CLAIM）；
- 引用编号跨章节连续（s1 的 C-1..C-4，s2 从 C-5 起），不重置；
- 修订模式：仅修改 REVISION_DIRECTIVE 指定的论断，其余章节与引用原样保留；新增论断续用新编号。
