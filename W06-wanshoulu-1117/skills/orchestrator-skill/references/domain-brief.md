# 年报业务要点（主 Agent 对话澄清用）

> 你不需要成为银行分析师（那是专家节点的活），但需要足够的业务常识来判断任务是否明确、何时该澄清。

## 一、任务澄清清单（缺哪项就问哪项，不要猜）

| 要素 | 示例 | 缺失后果 |
|---|---|---|
| 银行主体 | "招商银行" | 材料未冻结 → 拒绝并说明 |
| 报告期间 | "2025 年度" | 期间不明 → 指标无对比基数 |
| 口径 | 默认集团合并 | 母公司口径会触发能力排除 |
| 输出范围 | 全部章节 / 只资产质量 / 只经营 | 决定图裁剪 |
| 验收标准 | 默认八指标全核验+引用核验 | 特殊要求写进任务 |

## 二、八指标与三分析工位的对应（判断裁剪时用）

- **经营（finance-analyst）**：营业收入、归母净利润、净息差、成本收入比
- **资产质量（risk-analyst）**：不良贷款余额、不良贷款率、拨备覆盖率
- **资本（capital-analyst）**：核心一级资本充足率（CET1）

任务只要"资产质量分析"→ 图裁剪为 material→metrics→risk→writer→checker→approver（finance/capital 节点不进图）。

## 三、常见任务表述→图结构的映射直觉

- "做个年报简报" → 标准全拓扑
- "分析一下资产质量" → 裁剪图（risk 为主）
- "对比去年" → 确认对比基数页在冻结快照内（page-46 类）
- "按母公司口径" → 触发适用性排除流程，如实报告可用能力变化

## 四、交付相关常识（回答用户疑问时用）

- 为什么慢：双核验是确定性复算，逐数字对原文页，不是模型"看一眼"
- 为什么这个数字被拦：核验器给出规则号（N1-N7/L1），可以按号查释义
- 改一个字也要重新批准吗：是——批准绑定工件指纹，内容一改旧批准即失效（E03 防线，防止"检查后偷改"）
