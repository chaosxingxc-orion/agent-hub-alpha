# 生成前自检清单与规范约束

> 主 Agent 提交候选图前逐项自检。控制面（Go）会做机器校验，但**能在生成侧预防的不要留给打回**——每次打回都是一轮对话成本。

## 一、控制面会拒什么（机器校验清单）

| 校验 | 你的自检动作 |
|---|---|
| schema 合法 | 图 JSON 结构完整（节点/边/预算/版本四要素） |
| 能力存在 | 每个节点引用的能力 id 必须在目录（注册表/能力卡）里**当前存在** |
| 版本绑定 | 节点必填 `能力@版本`；不存在"最新版"这种引用 |
| 依赖有效 | 边指向的节点存在且无环（DAG）；join 节点声明全部前驱 |
| 循环有界 | 若声明修订环，必须带 `max_rounds` 且 ≥1 |
| 预算 | 图级预算字段存在且 >0；节点级预算之和 ≤ 图级 |

## 二、口径适用性规则（适用性过滤的结构化依据）

| 规则 | 说明 |
|---|---|
| 集团 vs 母公司 | 年报指标默认**集团合并口径**；任务指定母公司口径时，无母公司口径支持的能力全部排除 |
| 期间 | 年报默认"2025 年度+2024 对比基数"；任务要半年报时，年度类能力需确认可复用或排除 |
| 银行 | 当前冻结材料：招商银行（W01 快照）；任务指定其他银行时如实报"材料未冻结" |
| 指标子集 | 分析节点只消费骨架 `metric_keys` 声明的子集；任务要求超出八指标范围的论断 → 报"未覆盖"，不臆造 |

## 三、降级表（规约未覆盖时）

| 未覆盖情形 | 降级动作 |
|---|---|
| 指标不在八项之内 | 该论断不进正文，标注 `OUT_OF_SCOPE` |
| 对比基数缺失 | 同比类分析降级为"单期陈述"，不推算 |
| 图表规格未定义 | chart 节点不进图（无数据可渲染时宁缺勿滥） |

## 四、W01 规约引用

- 材料：招商银行 2025 年报冻结快照（SHA 52c49dcd…，PR #21 @ ae17ee3）
- 指标：八项（OPERATING_REVENUE / NET_PROFIT_ATTRIBUTABLE / NET_INTEREST_MARGIN / COST_INCOME_RATIO / NPL_BALANCE / NPL_RATIO / PROVISION_COVERAGE / CET1_RATIO）
- 反例：10 条（含百分比/百分点混淆——N7 规则拦）
- 交付谓词：数值核验 PASSED ∧ 引用核验 PASSED ∧ 用户确认 ∧ 三记录绑定同一工件指纹
